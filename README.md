## `/about`

I'm a developer and independent security researcher from Indonesia, focused on **offensive security, full-stack engineering, automation, and building real-world platforms**.

My approach sits at the intersection of development and security:

- Build software with an attacker's mindset.
- Study how systems break.
- Understand the root cause.
- Document what matters.
- Rebuild with better engineering.

I work primarily with **JavaScript, Node.js, Python, Bash, Linux, web technologies, and security tooling**.

My daily environment is **Arch Linux + Hyprland**.
